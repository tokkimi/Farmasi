# Haru — 21 septembre 2026

## Livré
Six chapitres français développés avec exemples, exercices et vérification des acquis. Navigation mobile par sélection, titres sans police display, lecture en une colonne. Scanner visage mis en avant dans le premier écran et section dédiée. Retour après connexion corrigé. Onze guides avec onze fichiers de portraits distincts. Suivi : décompte des notes/jours UTC et jours sans note, conclusion « pas assez de recul », cinq derniers bilans.

Les autres langues conservent leurs cours précédents : cette livraison enrichit le contenu français, et corrige la mise en page dans toutes les langues.

## Recherche et positionnement
Le scan et la personnalisation seuls ne constituent pas une nouveauté démontrée. Exemples consultés :
- https://patents.google.com/patent/US20200202131A1/en : détection d'interactions vidéo et routine personnalisée.
- https://patents.google.com/patent/US20200111577A1/en : formulation personnalisée et données de suivi.
- https://patents.google.com/patent/US20250191486A1/en : routine audiovisuelle personnalisée.
- https://getskinbliss.com/blog/skin-bliss-app-faq/ : scan, suivi et routines déjà présents sur le marché.

La valeur retenue pour Haru est un suivi compréhensible qui distingue les observations, les informations manquantes et une décision personnelle. Aucun score d'efficacité ni lien causal automatique. Il s'agit d'une orientation produit, pas d'une analyse de brevetabilité ou de liberté d'exploitation.

## Visuels
Huit portraits générés avec image_gen, contrôlés visuellement puis optimisés WebP 800 px, qualité 82. Fichiers public/images/routine-{acne-prone,sensitive-barrier,anti-aging,minimalist,pregnancy-safe,winter,summer,teen}.webp.
Prompt commun : portrait photographique naturel, visage rapproché expressif, pores visibles, lumière du jour, une personne différente par guide, sans texte ni retouche plastique. Variantes : boutons légers pour acne-prone ; rougeurs discrètes pour sensitive-barrier ; peau adulte avec lignes naturelles pour anti-aging ; portrait simple pour minimalist ; adulte souriante pour pregnancy-safe ; joues mates et maille pour winter ; crème solaire sur la joue pour summer ; jeune adulte de 18 ans avec quelques imperfections pour teen. Les images illustrent les guides, sans établir un diagnostic ni déduire une grossesse d'un visage.
